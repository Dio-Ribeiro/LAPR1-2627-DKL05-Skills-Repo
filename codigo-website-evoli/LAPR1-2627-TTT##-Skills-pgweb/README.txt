Como usar: abrir o ficheiro index.html num navegador (não são necessárias instalações).

Estrutura:
  index.html     — página web do projeto (entregável do Sprint 2)
  favicon.svg    — logótipo/marca EVOLI (rebento)
  assets/css     — estilos próprios (style.css)
  assets/js      — interações (main.js: scroll suave, revelações ao scroll, parallax)
  assets/img     — imagens (mascote EVOLI, fases do ecossistema, logótipo ISEP, fotografias)
  assets/vendor  — Bootstrap 5.3.3, Bootstrap Icons e Lenis (funciona offline)

Créditos das imagens: Unsplash (fotografias), Wikimedia Commons (logótipo ISEP),
